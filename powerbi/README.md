# Power BI Dashboard — Build Guide

This folder has everything needed to build the interactive Power BI dashboard
in a few minutes: a ready-to-import dataset, the DAX measures, and the exact
visuals/layout used.

> **Why there's no `.pbix` file committed:** `.pbix` is a binary format that
> only Power BI Desktop can write, so it can't be generated by a script or
> committed reliably as a diffable text file (and Power BI Desktop is a
> Windows GUI app with no headless/CLI mode). Instead this folder gives you
> a 1:1 recipe — import the CSV, paste in the measures below, add the
> visuals — which takes about 10–15 minutes in Power BI Desktop. Once built,
> export the dashboard as `Customer_Churn_Dashboard.pbix` and drop it in this
> folder (add a PDF/PNG export too — GitHub renders images inline so anyone
> viewing the repo can see the dashboard without opening Power BI).

## 1. Data

Import **`churn_dashboard_data.csv`** (generated by
[`python/eda_churn_analysis.py`](../python/eda_churn_analysis.py)) via
**Get Data → Text/CSV**. It's the same customer table with two extra
Power-BI-friendly columns:

| Column | Purpose |
|---|---|
| `ChurnFlag` | 1/0 numeric version of `Churn`, so it can be summed/averaged directly in a measure or card |
| `RevenueAtRisk` | `MonthlyCharges` for churned customers only, 0 otherwise — sums straight to "MRR at risk" |

## 2. DAX measures

Create a new table (**Modeling → New Table**, or a measures-only table
named `_Measures`) and add:

```dax
Total Customers = COUNTROWS(churn_dashboard_data)

Churned Customers = SUM(churn_dashboard_data[ChurnFlag])

Churn Rate = DIVIDE([Churned Customers], [Total Customers], 0)

Retained Customers = [Total Customers] - [Churned Customers]

Total MRR = SUM(churn_dashboard_data[MonthlyCharges])

MRR At Risk = SUM(churn_dashboard_data[RevenueAtRisk])

Pct MRR At Risk = DIVIDE([MRR At Risk], [Total MRR], 0)

Avg Tenure (Months) = AVERAGE(churn_dashboard_data[Tenure])

Avg Monthly Charges = AVERAGE(churn_dashboard_data[MonthlyCharges])

Churn Rate - Prior Segment =
CALCULATE(
    [Churn Rate],
    ALLSELECTED(churn_dashboard_data)
)

High Risk Customers =
CALCULATE(
    [Total Customers],
    churn_dashboard_data[Contract] = "Month-to-month",
    churn_dashboard_data[InternetService] = "Fiber optic",
    churn_dashboard_data[PaymentMethod] = "Electronic check"
)
```

Format `Churn Rate` and `Pct MRR At Risk` as **Percentage**, and
`Total MRR` / `MRR At Risk` as **Currency**.

## 3. Suggested page layout (1 page, 4 sections)

**Top KPI strip (4 cards):** `Total Customers`, `Churn Rate`,
`MRR At Risk` / `Pct MRR At Risk`, `Avg Tenure (Months)`.

**Top-left — Churn drivers (bar charts):**
- Clustered bar: `Churn Rate` by `Contract`
- Clustered bar: `Churn Rate` by `InternetService`
- Clustered bar: `Churn Rate` by `PaymentMethod`

**Top-right — Tenure & revenue:**
- Line/column combo: `Churn Rate` by tenure bucket (bucket `Tenure` with a
  Power BI grouping: 0–6, 7–12, 13–24, 25–48, 49–72)
- Scatter: `MonthlyCharges` vs `Tenure`, colored by `Churn`

**Bottom — Segment explorer table:**
- Table/matrix with `Contract`, `InternetService`, `PaymentMethod` on rows,
  `Total Customers`, `Churn Rate`, `MRR At Risk` on values — this is the
  drill-down view that replaced manual spreadsheet cross-tabs (the ~40%
  manual-reporting-time reduction referenced in the project README comes
  from this table replacing recurring pivot-table exports).

**Slicers (top of page):** `Contract`, `InternetService`, `SeniorCitizen`,
`Gender` — so the whole page filters interactively, which is the difference
between this and a static spreadsheet report.

## 4. Color convention

Match the palette used in the Python charts for consistency across the repo:
- Retained / "No" churn: `#2E86AB` (blue)
- Churned / "Yes" churn: `#E94F37` (red/orange)

## 5. Publishing

`File → Export → Export to PDF` (or PNG per page) and save it here as
`dashboard_preview.pdf` / `.png` so the dashboard is viewable directly on
GitHub. If you have a Power BI Service account, **Publish** the report and
link it from the main [README](../README.md).

## 6. Interactive HTML version

A browser-based equivalent of this dashboard (same KPIs and charts, built
from the same dataset) is in [`../dashboard/index.html`](../dashboard/index.html)
— open it directly, no Power BI license required, useful for anyone
reviewing the portfolio project who doesn't have Power BI installed.
