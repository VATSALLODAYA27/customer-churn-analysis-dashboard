    How to use the drivers

    • Lift compares each group to the current average, so it answers "who is worse than typical?"Groups with fewer than 30 customers are hidden.
    • Model coefficients show what still matters after controlling for the other factors.Right = raises churn, left = lowers it.
    • Filters re-cut the lift chart live, e.g. select "Month-to-month" to see what separates churners inside that group.
